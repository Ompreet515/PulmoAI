# Multimodal Explainable Pneumonia Detection

This project implements a multimodal deep learning framework for
pneumonia detection using Chest X-ray and CT scan images.

## Features
- X-ray based pneumonia detection (MobileNetV2)
- CT scan based pneumonia detection (ResNet50)
- Explainable AI using Grad-CAM
- Multimodal decision fusion with confidence score
